### OpenAI Pushes the Perplexity Debate Toward a Shared Evaluation Standard

OpenAI has published an analysis of perplexity as a measure of progress in AI models, arguing for a more rigorous, shared approach to evaluating emerging capabilities. Perplexity — a statistical measure of how well a model predicts the next token — has long been used as a training benchmark, but its relationship to actual model intelligence and usefulness is frequently misread. The post aims to clarify what perplexity does and does not capture, positioning it as one input among many in a broader evaluation toolkit. This matters because the industry lacks consensus on how to measure capability as models grow more capable and more general, and fragmented benchmarks invite both exaggeration and dismissal. A shared approach could improve comparability across labs and inform regulatory and procurement decisions — though competitors may resist standardizing on metrics they don't control.

### Gemini API Adds Tool Retrieval to Scale Agent Toolchains

Google has introduced Tool Retrieval in the Gemini API (now in preview), letting developers give agents access to hundreds of tools while consuming fewer tokens. The design addresses a core scaling problem in agentic systems: stuffing every tool schema into context is expensive and degrades selection accuracy as the tool count grows. By retrieving only relevant tools per query, agents can operate over large enterprise tool catalogs with better precision and lower cost. This is a pragmatic infrastructure play — tool proliferation is now the bottleneck for enterprise agents, not model intelligence.
