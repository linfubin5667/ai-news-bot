### Google Adds Tool Retrieval to Gemini API for Scalable Agent Tooling

Google has launched Tool Retrieval in the Gemini API in preview, enabling agents to access hundreds of tools while consuming fewer tokens. The feature addresses a core scaling bottleneck in agent architectures: as tool libraries grow, injecting full tool definitions into context becomes prohibitively expensive and degrades model performance. This is an infrastructure-level enabler for enterprise agent deployments where dozens of internal APIs and services must be exposed to a single agent. Formal verification of production cryptographic code at this scale represents a landmark for AI-assisted software assurance: proofs in Lean provide machine-checked guarantees that code behaves as specified, eliminating entire classes of implementation bugs. Three million lines of machine-generated proofs would be infeasible for human teams at reasonable cost, demonstrating AI's capacity to compress verification timelines for safety-critical software. If this approach generalizes, it could reshape security engineering for cryptography, operating systems, and other high-assurance domains—and gives DeepMind a credible claim to leadership in AI-driven formal methods.
